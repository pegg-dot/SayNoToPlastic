### Detection methods

There is no single universal microplastic test. The production methods page should continue to point readers to the named method and contamination controls for each linked primary study. A review can explain method families, but it should not replace study-level method reporting.

## Review workflow

For every candidate paper:

1. retrieve the full text and any supplement;
2. record sample size, population, matrix/tissue, collection materials, blanks/controls, digestion method, instrument, size threshold, polymer-identification rule, and units;
3. separate particle count from polymer mass;
4. identify whether the study is detection-only, mechanistic, observational, or outcome-based;
5. compare the website sentence with the paper's actual result and limitations;
6. obtain medical/editorial approval;
7. only then move a page from `source-review` to `partial` or `verified`.
