# v40.11 — Compact editorial footer

Date: 2026-08-08

## Rendered defect
The local desktop review showed that the footer links, descriptions, legal row, and signup area were oversized and vertically loose. The serif description copy also made the footer read like another editorial content block instead of compact website chrome.

## Correction
- Footer navigation and descriptive copy now use the site's sans-serif UI family.
- Desktop navigation links are reduced to 12px with compact line height and 26px rows.
- Section labels are reduced to 9px with restrained tracking.
- Brand and Field Notes descriptions are reduced to 12.5px sans-serif.
- Main footer padding is reduced from 70px to 44px at desktop sizes.
- Footer signup inputs, consent copy, and CTA are compacted without changing form behavior.
- Legal/utility copy is reduced to 10px and no longer receives 48px-high desktop link boxes.
- Mobile keeps larger touch-friendly rows while remaining visually tighter than v40.10.

## Intentionally unchanged
- all footer links and destinations;
- signup, consent, privacy reset, analytics, and form APIs;
- footer wordmark and gold movement mark;
- Earth/inheritance quote section;
- welcome-film modal and replay trigger;
- package lock, dependencies, commerce mode, and production Sites v30.
